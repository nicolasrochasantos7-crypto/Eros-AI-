# Eros AI

> Uma inteligência artificial em desenvolvimento, construída com o objetivo de criar uma experiência de conversa personalizada.

## Sobre o projeto

A **Eros AI** é um projeto pessoal no qual estou trabalhando para desenvolver minha própria solução de inteligência artificial, começando pela criação de uma interface de conversa que corresponda à experiência que desejo oferecer.

Atualmente, estou desenvolvendo a estrutura visual utilizando HTML e CSS. A proposta é construir primeiro a interface do chat e, posteriormente, integrá-la à inteligência artificial, conforme eu avançar nos estudos e definir a arquitetura do projeto.

## Estado atual

🚧 **Em desenvolvimento**

O projeto ainda está em sua fase inicial. Neste momento, meu foco está na construção da interface, na organização dos elementos visuais e no estudo das tecnologias e abordagens necessárias para desenvolver a inteligência artificial.

Ainda existem diversas etapas de planejamento, aprendizado e implementação antes que a Eros AI possa funcionar como uma aplicação completa.

## Objetivos

- Desenvolver uma interface de chat própria.
- Estudar e definir a arquitetura da aplicação.
- Pesquisar as tecnologias necessárias para implementar a inteligência artificial.
- Integrar a interface à solução de IA quando essa etapa estiver pronta.
- Evoluir o projeto de forma gradual, aplicando na prática os conhecimentos adquiridos.

## Tecnologias

- HTML
- CSS

*Tecnologias utilizadas na interface até o momento. A stack do restante da aplicação ainda está em estudo.*

## Aprendizado e colaboração

Este projeto também faz parte da minha jornada de aprendizado em programação. Quero compreender cada etapa do desenvolvimento, desde a construção da interface até a integração com a inteligência artificial, buscando soluções que façam sentido para a proposta.

Sugestões construtivas, ideias de arquitetura e recomendações de tecnologias são bem-vindas. Estou aberto a aprender com outras pessoas e aprimorar o projeto ao longo do desenvolvimento.

## Próximos passos

As próximas etapas serão definidas conforme o avanço dos estudos e a evolução do projeto. A prioridade atual é desenvolver a interface e entender como estruturar os componentes necessários para as próximas fases.
